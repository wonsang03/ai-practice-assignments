# 전체 정답 검증

## 1. 자동 검사 (실패하면 여기서 멈추고 보고)
- `node tests/run.js` — 형식, 정답 번호 범위, 보기 중복, 난이도, 정답 위치 편향, 중복 문제.
- `node tools/quiz.js dupes` — 문장·코드가 같은 문제.

## 2. 내용 검증
`node tools/quiz.js list` 로 목록을 본 뒤 `js/questions.js`를 읽고 문제마다 확인한다.
- 정답 보기가 해설과 일치하는가, 해설이 정답의 근거를 설명하는가.
- "~이 아닌 것" 문제: 정답 외 세 보기가 모두 맞는 설명인가(정답이 둘이 되지 않는가).
- 코드 출력 문제(`code` 필드): 실제로 실행해 출력이 정답과 같은지 확인한다. 실행할 수 없는 환경이면 "미실행"으로 표시한다.
- 같은 개념을 거의 같은 방식으로 묻는 **유사 문제**(언어만 다른 같은 코드 등)도 찾아 둔다.
- 난이도 표시(초급·중급·상급)가 크게 어긋나 보이는 문제.

## 3. 보고
- 자동 검사 결과(통과 개수).
- 문제 있는 항목만 표로: `id | 유형(정답 오류/복수 정답/해설 부족/유사 문제/난이도) | 근거 | 제안`.
- 문제가 없으면 "전체 N문제 이상 없음"이라고 짧게.

이 명령은 **검증만** 한다. 수정은 사용자 확인 후 진행한다. 확신이 없는 항목은 "확인 필요"로 둔다.
