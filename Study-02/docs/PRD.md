# PRD — 개인용 할 일 관리 앱

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 매일 해야 할 일 10~20개를 빠르게 적고, 끝낸 일을 체크하며, 카테고리별 진행 상황과 기간(과제 마감 등)을 달력으로 한눈에 본다 |
| 사용자 | 혼자 쓰는 개인 (학생·직장인) |
| 플랫폼 | 데스크톱·모바일 웹 브라우저. 설치 없이 `index.html`을 열어 실행 |
| 기술 제약 | 순수 HTML·CSS·자바스크립트. 프레임워크·빌드 도구·서버 없음 |
| 저장 | 할 일·설정은 localStorage, 사진은 IndexedDB. 새로고침해도 유지 |

## 2. 기능 요구사항

### 2.1 할 일 관리 (필수)

- 추가: 내용(필수, 최대 200자), 카테고리(업무/개인/공부), 시작일·마감일(선택)
- 수정: 할 일을 누르거나 더블클릭·수정 버튼·F2로 상세 창을 열어 모든 항목 수정
- 삭제: 개별 삭제, 완료 항목 일괄 삭제. 삭제 직후 되돌리기 가능
- 완료: 체크박스로 완료/미완료 전환. 완료 항목은 별도 영역에 모음
- 빠른 입력: `#카테고리`, `@마감일`, `@시작~마감` 표기를 입력창에서 바로 해석하고 미리 보여 줌

### 2.2 자세한 내용

- 메모: 여러 줄, 최대 5,000자. 목록에 첫 줄 미리보기, 검색 대상에 포함
- 사진: 할 일당 최대 10장. 파일 선택·끌어다 놓기·붙여넣기. 큰 사진은 줄여서 저장. 눌러서 크게 보기
- 상세 창: 닫기·Esc는 저장, 취소는 버림. 제목이 비면 저장하지 않음

### 2.3 달력

- 월 달력(일요일 시작), 이전/다음 달, 오늘로 이동
- 할 일을 시작일(없으면 등록일)부터 마감일(없으면 그날)까지 선으로 표시, 주를 넘으면 이어서 표시
- 겹치는 일은 줄을 나눠 표시하고, 자리가 모자라면 `+N`
- 날짜를 누르면 그날 걸친 할 일 목록(완료 체크 가능), 선을 누르면 상세 창
- 고른 날짜를 마감일로 바로 추가
- 카테고리 필터·검색 적용, 기한 지남·완료 상태 구분

### 2.4 분류·탐색 (목록)

- 카테고리 필터: 전체/업무/개인/공부, 남은 개수 표시
- 검색: 입력 즉시 제목·메모·카테고리 이름으로 걸러냄
- 정렬: 직접(드래그)·최신·오래된·마감일·카테고리. 선택 저장
- 직접 정렬: 마우스·터치 드래그, 키보드 Alt+↑/↓. 필터 중 이동해도 숨은 항목 위치 유지

### 2.5 진행률 대시보드

- 전체 진행률 (완료/전체, %), 오늘 추가 개수
- 카테고리별 진행률 (누르면 해당 카테고리로 필터)
- 남은 할 일, 오늘 완료, 오늘 마감, 기한 지남
- 최근 7일 날짜별 완료 개수 막대그래프
- 오늘의 문장 (날짜마다 바뀌고 버튼으로 넘길 수 있음)
- 대시보드 접기/펼치기 (상태 저장)

### 2.6 설정·데이터

- 다크 모드: 기본은 운영체제 설정, 토글로 고정 가능, 새로고침 시 깜빡임 없음
- 보기 방식(목록/달력) 저장
- 내보내기: JSON 파일 (`my-tasks-YYYY-MM-DD.json`), 사진 포함
- 가져오기: 합치기/모두 바꾸기 선택, 가져오기 전 자동 백업, 직후 되돌리기, 형식 오류 안내.
  이전 버전(강의 예제) 형식도 읽음

### 2.7 키보드 단축키

Alt+N 입력, / 검색, Alt+1~4 필터, Alt+L/Alt+C 목록/달력, PageUp/PageDown 달 이동, Alt+T 다크 모드,
Ctrl+Z 되돌리기, Enter/F2 상세 창, Delete 삭제, ? 도움말

## 3. 비기능 요구사항

- **성능**: 100개 이상에서도 체크·검색·달력 전환이 끊김 없이 반응. 바뀐 항목만 다시 그림
- **안전성**: 사용자 입력을 HTML로 해석하지 않음. 가져온 파일은 항목별로 검증하고 사진은 이미지 data URL만 허용. 저장 실패 시 안내
- **접근성**: 키보드로 모든 기능 사용, 버튼마다 이름(aria-label), 상태 변화는 화면 낭독기에 알림,
  동작 줄이기 설정 시 애니메이션 끔, 카테고리 색은 색각이상에서도 구분되고 항상 글자와 함께 표시
- **반응형**: 375px 폭 휴대폰에서 가로 스크롤 없음, 터치로 드래그·수정·사진 첨부 가능

## 4. 제외 범위

- 우선순위, 연속 달성 일수 (사용자 요청으로 제외)
- 계정·서버 동기화
- 사용자 정의 카테고리
- 하위 할 일, 반복 일정, 알림
- 달력에서 선을 끌어 날짜 바꾸기

## 5. 완료 기준

- 위 기능이 브라우저에서 동작하고 새로고침 후에도 유지된다 (사진 포함)
- `node --test`의 로직 테스트가 모두 통과한다
- 라이트/다크, 데스크톱/모바일 화면에서 레이아웃이 깨지지 않는다
