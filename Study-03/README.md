# 정보처리기사 퀴즈

정보처리기사 필기 5과목을 4지선다로 풀어 보는 퀴즈 게임입니다.
순수 HTML·CSS·자바스크립트로 만들었고, 설치 없이 브라우저에서 바로 실행됩니다.

> 인공지능활용실습 — 07. 할루시네이션 없는 AI 콘텐츠 만들기 · 08. 자동화로 개발 효율 높이기 · 09. 명령어 체이닝을 통한 유지보수 전략

## 실행

설치할 것이 없습니다. `Study-03` 폴더의 **`index.html`을 더블 클릭**하면 기본 브라우저(크롬·엣지 등)에서 바로 열립니다.
인터넷이 없어도 됩니다.

## 사용 방법 (처음 하는 분)

### 1. 게임 시작하기

1. 시작 화면의 **이름** 칸에 이름을 적습니다. 순위표와 통계에 이 이름으로 기록됩니다(비워 두면 "익명").
2. **모드**를 고릅니다.
   - **도전 모드**: 실력 확인용. 점수가 순위표에 올라갑니다.
   - **스피드 퀴즈**: 문제마다 15초 안에 답해야 합니다. 빨리 맞힐수록 보너스 점수가 붙습니다.
   - **N과목 연습**: 한 과목만 집중해서 전부 풀어 봅니다(순위표에는 안 올라가고 통계에는 남음).
3. 도전·스피드 모드는 **문제 수**(5·10·15·25·50)를 고릅니다. 5과목에서 같은 수씩 골고루 나옵니다.
4. **[게임 시작]** 을 누릅니다.

### 2. 문제 풀기

- 보기를 클릭하거나 키보드 **`1`~`4`** 를 누르면 답이 됩니다.
- 답하면 바로 **정답/오답과 해설**이 나옵니다. 정답은 초록 ✔, 내가 고른 오답은 빨간 ✖로 표시됩니다.
- 모르겠으면 **💡 힌트**(또는 **`H`** 키)를 누르세요. 틀린 보기 2개가 지워지는 대신, 맞혀도 5점만 받습니다.
- 위쪽에서 진행(예: 3 / 10), 과목, 난이도(초급·중급·상급), 걸린 시간, 현재 점수를 볼 수 있습니다.
- 스피드 퀴즈에서는 시간 막대가 줄어들고, 5초 이하가 되면 빨간색으로 바뀝니다. 0초가 되면 오답 처리됩니다.
- **[다음 문제]**(또는 **Enter**)로 넘어갑니다.

### 3. 결과 확인

- 점수, 정답률, 힌트·시간 초과 횟수, **과목별 정답 막대**, **틀린 문제와 해설**이 나옵니다.
- **[틀린 문제만 다시 풀기]**: 방금 틀린 문제만 다시 풀어 복습합니다.
- **[순위 확인]** / **[내 통계]**: 순위표와 통계 화면으로 바로 갑니다.
- **[다시 도전]**: 시작 화면으로 돌아갑니다.

### 4. 위쪽 메뉴

- **🏆 순위**: 모드와 문제 수를 골라 상위 10명을 봅니다. 방금 푼 기록은 강조 표시됩니다. 맨 아래 **순위표 전체 초기화**로 지울 수 있습니다.
- **📊 통계**: 지금 이름으로 푼 기록을 모아 보여 줍니다. 누적 정답률·최고 점수·학습 시간, 과목별·난이도별 정답률, **자주 틀린 문제**(정답·해설 포함), 최근 기록 10개, 목표까지 남은 정답률.
  - **기록 내보내기 (JSON)**: 기록 파일을 받습니다(선생님 모드에 사용).
  - **내 기록 삭제**: 지금 이름의 플레이 기록만 지웁니다(순위표는 남음).
- **🙂 프로필**: 이름, 아바타, 목표 정답률(60~90%)을 정합니다. 이름을 바꾸면 기존 기록을 새 이름으로 옮길지 물어봅니다.

> 기록은 **이 컴퓨터의 이 브라우저**에만 저장됩니다. 다른 브라우저나 시크릿 창에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 지워집니다.
> 한 컴퓨터를 여럿이 쓸 때는 각자 다른 이름으로 시작하면 통계가 이름별로 따로 모입니다.

## 게임 방식 (정리)

- **문제 수는 5·10·15·25·50개** 중에서 고릅니다(5과목에서 같은 수씩 무작위로 뽑음). 순위표는 문제 수별로 따로 관리합니다.
- 5과목(소프트웨어 설계 / 소프트웨어 개발 / 데이터베이스 구축 / 프로그래밍 언어 활용 / 정보시스템 구축관리)에서 기본은 **총 10문제(과목당 2문제)** 입니다. 문제 은행에는 과목당 10문제, 총 50문제가 있습니다.
- 문제를 풀 때마다 **정답 여부와 해설**을 바로 보여 줍니다. 보기 순서는 매번 섞이고, 숫자키 `1`~`4`로도 고를 수 있습니다.
- **모드 3가지**
  - **도전 모드**: 문제당 10점이고, 순위표에 기록됩니다.
  - **스피드 퀴즈**: 문제당 **15초** 제한이 있습니다. 시간이 지나면 오답으로 처리되고, 남은 시간 3초마다 보너스 1점(최대 +5점)을 받습니다. 순위표는 따로 관리합니다.
  - **과목 연습**: 고른 과목의 문제를 전부 풉니다. 순위표에는 기록되지 않습니다.
- **힌트**: 문제마다 한 번, 💡 버튼(또는 `H` 키)으로 오답 보기 2개를 지울 수 있습니다. 대신 맞히면 10점이 아니라 **5점**만 받습니다.
- **난이도**: 모든 문제에 초급·중급·상급이 표시됩니다.
- 결과 화면의 **틀린 문제만 다시 풀기**로 오답을 바로 복습할 수 있습니다.
- 끝나면 점수, 정답률, 힌트·시간 초과 횟수, 과목별 정답 수, **틀린 문제 복습**을 보여 줍니다.
- 상단 메뉴
  - **🏆 순위(리더보드)**: 모드·문제 수별 상위 10명을 보여 줍니다. 점수가 높은 순, 같으면 시간이 짧은 순입니다.
  - **📊 통계 대시보드**:
    - 누적 정답률, 최고 점수, 학습 시간
    - 과목별·난이도별 정답률
    - 자주 틀린 문제, 최근 기록, 목표 달성도
  - **🙂 프로필**: 이름, 아바타, 목표 정답률을 정합니다.
- 기록은 모두 이 브라우저(localStorage)에 저장됩니다. 통계 화면의 **기록 내보내기**로 JSON 파일을 받을 수 있고, 이 파일이 선생님 모드의 입력이 됩니다.

## 할루시네이션 대응 (강의 내용 반영)

강의의 핵심은 "AI가 만든 콘텐츠를 그대로 믿지 말고 검증하라"입니다. 이 프로젝트는 다음과 같이 반영했습니다.

| 강의 내용 | 이 프로젝트 |
| --- | --- |
| 검증 가이드라인을 `CLAUDE.md`에 영구 저장 | [`CLAUDE.md`](CLAUDE.md)에 문제 검증 규칙 7가지를 적어 둠 |
| 논란 있는 정보는 기준을 명시 (예: 가장 긴 강) | 정답이 둘이 될 수 있는 문제는 출제하지 않음. "~이 아닌 것" 문제는 오답 보기까지 검증 |
| 정답과 함께 추가 정보 안내 | 모든 문제에 해설(`explanation`) 포함 |
| 직접 테스트 | `node tests/run.js`로 문제 형식·섞기 후 정답 유지·순위 정렬 검사, 코드 출력 문제는 실제로 컴파일·실행해 확인 |

## 커스텀 명령어로 자동화 (08·09 강의 반영)

이 폴더에서 `claude`를 실행하면 `.claude/commands/`의 프로젝트 명령어를 쓸 수 있습니다. 명령어를 추가·수정한 뒤에는 클로드 코드를 다시 시작해야 반영됩니다.
개수·평균·분포 같은 숫자는 명령어가 `tools/` 스크립트를 실행해서 얻습니다. AI가 숫자를 직접 세다가 틀리는 일(할루시네이션)을 막기 위해서입니다.

**쓰는 방법**

1. 파일 탐색기에서 `Study-03` 폴더를 열고, 주소창에 `cmd`를 입력해 그 위치에서 명령 프롬프트를 엽니다.
2. `claude`를 입력해 클로드 코드를 실행합니다.
3. `/`를 입력하면 명령어 목록이 나옵니다. 예를 들어 `/quiz-stats`를 입력하고 Enter를 누르면 문제 은행 통계를 보여 줍니다.
4. 인수가 필요한 명령은 뒤에 띄어서 적습니다. 예: `/quiz-range 1 20`, `/quiz-add 데이터베이스 중급`, `/quiz-validate 3`
   - 과목은 이름(`데이터베이스 구축`), 줄임말(`DB`), 번호(`3`), 키(`database`) 모두 됩니다.
5. 문제를 고치는 명령(`/quiz-add`, `/quiz-daily`, `/quiz-validate`의 수정 단계)은 클로드 코드가 바꾸기 전에 허락을 물어봅니다. 내용을 확인하고 승인하세요.

클로드 코드 없이 숫자만 보고 싶으면 스크립트를 직접 실행해도 됩니다(Node.js 필요).

```
node tools/quiz.js stats           # 문제 은행 통계
node tools/quiz.js range 1 20      # 1~20번 구간 분석
node tools/quiz.js superlatives    # 최상급 표현이 들어간 문제
node tools/teacher.js all          # 선생님 모드 보고서 + CSV
```

| 강의 | 명령어 | 하는 일 |
| --- | --- | --- |
| 08 | `/quiz-validate [과목]` | '가장·최초·최대' 같은 최상급 표현을 찾고, 기준이 명확한지 판정한 뒤 수정안을 냅니다. 인수 플레이스홀더는 `$ARGUMENTS`입니다. |
| 08 | `/quiz-range 1 20` | 1~20번 문제의 난이도 평균·표준편차와 정답 위치 편향을 분석합니다. 위치 인수는 `$1`, `$2`입니다. |
| 08 | `/quiz-add 데이터베이스 중급` | 템플릿과 검증 가이드라인에 맞춰 새 문제를 추가하고 테스트합니다. |
| 09 | `/quiz-check` | 전체 문제의 형식과 중복을 검사하고, 정답을 교차 검증합니다. |
| 09 | `/quiz-stats` | 과목별 문항 수, 난이도 분포, 정답 위치 편향을 보여 줍니다. |
| 09 | `/quiz-leaderboard` | 모은 기록으로 학생별 최고 점수 리더보드를 만듭니다. |
| 09 | `/quiz-daily` | 일일 업데이트입니다. 구조 파악 → 분포 확인 → 결손 파악 → 백업 → 중복 체크 → 새 문제 추가·검증 → 리포트 순서로 진행하고, 실패하면 즉시 멈춥니다. |
| 09 | `/teacher-dashboard` | 선생님 모드입니다. `/collect-results` → `/create-report`(상대평가 등급) → `/export-report`(CSV) 순서로 실행합니다. |

명령어 체이닝 예시: `/quiz-add 데이터베이스 상급 && /quiz-check && /quiz-stats`

### 선생님 모드 사용법

1. 학생마다 퀴즈의 **📊 통계 → ⬇️ 기록 내보내기**로 `quiz-results-이름-날짜.json` 파일을 받습니다.
2. 받은 파일을 `data/results/` 폴더에 모읍니다. 실제 학생 기록은 `.gitignore`로 커밋에서 제외됩니다.
3. `/teacher-dashboard`를 실행합니다. 명령어 없이 `node tools/teacher.js all`로 실행해도 됩니다.
4. 결과 파일이 두 개 만들어집니다.
   - `teacher_report.html`: 학생별 순위·등급·약한 과목, 반 전체 과목별 정답률, 자주 틀린 문제
   - `report_detailed.csv`: 엑셀용 상세 표

등급은 **상대평가**입니다. 정답률 순위로 상위 30%는 A, 다음 40%는 B, 나머지는 C입니다. 저장소의 `data/results/demo-class.json`과 보고서 두 파일은 `node tools/teacher.js demo`로 만든 **시연용 가상 데이터**입니다. 데모학생01~08은 실제 학생이 아닙니다.

> **주의**: 문제는 정보처리기사 출제기준과 일반 교재 내용을 바탕으로 작성했으며 기출문제를 그대로 옮긴 것이 아닙니다.
> 시험 대비용으로 쓰기 전에 Q-net(한국산업인력공단)의 출제기준과 교재로 한 번 더 교차 검증하세요.

## 문제 추가하기

`js/questions.js`의 `QUESTIONS` 배열에 아래 형식으로 추가하고 `node tests/run.js`를 실행합니다.

```js
{
  id: "d11", category: "design",          // design | develop | database | language | system
  difficulty: 2,                           // 1 초급 · 2 중급 · 3 상급
  question: "문제 문장",
  choices: ["보기1", "보기2", "보기3", "보기4"],
  answer: 0,                               // 정답 보기의 번호(0부터)
  explanation: "정답인 이유"
}
```

코드 출력 문제는 `code: "소스 코드"` 필드를 추가하면 코드 블록으로 표시됩니다.
