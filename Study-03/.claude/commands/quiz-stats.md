# 문제 은행 통계

1. `node tools/quiz.js stats` 를 실행한다. 숫자는 스크립트 결과만 쓴다.
2. 결과를 짧게 정리한다.
   - 총 문항 수와 과목별 문항 수(과목 사이 차이가 2문제 이상이면 표시).
   - 난이도: 전체·과목별 평균과 초급/중급/상급 개수. 상급이 없거나 한 과목에 몰렸으면 표시.
   - 정답 위치 분포: ⚠ 표시가 있으면 어느 과목, 어느 위치인지.
   - 중복 문제 여부.
3. 다음에 할 일을 1~3개 제안한다(예: "/quiz-add 데이터베이스 상급으로 DB 상급 문제 보충").
