# 냉장고를 부탁해

냉장고 안을 찍은 사진을 올리면 AI가 **식재료를 찾아 주고**, 그 재료로 만들 수 있는 **요리 레시피를 추천**해 주는 웹 앱입니다.

> 인공지능활용실습 — 11. API 설정 / 12. API 활용

```
① 냉장고 사진 올리기  →  ② AI가 재료 인식  →  ③ 재료 고치기  →  ④ 레시피 추천
```

## 진행 상황

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1단계 | 냉장고 사진 → 식재료 인식 (Gemma 4 비전 모델) | ✅ 구현 ([PRD_step1.md](PRD_step1.md)) |
| 2단계 | 재료 → 레시피 추천 (GPT) | ✅ 구현 ([PRD_step2.md](PRD_step2.md)) |
| 3단계 | 로그인·레시피 저장·대시보드 | 📝 PRD만 작성 ([PRD_step3.md](PRD_step3.md)) |

## 1. 처음 한 번만 하는 준비

### ① 파이썬이 설치되어 있는지 확인

명령 프롬프트(또는 PowerShell)를 열고 아래를 입력합니다.

```
python --version
```

`Python 3.10` 이상이 나오면 됩니다. "python을 찾을 수 없습니다"가 나오면 [python.org](https://www.python.org/downloads/)에서 설치하고,
설치 첫 화면의 **"Add python.exe to PATH"** 에 꼭 체크하세요.

### ② 필요한 프로그램(패키지) 설치

`Study-04` 폴더에서 명령 프롬프트를 열고 아래를 입력합니다. (파일 탐색기에서 `Study-04` 폴더를 연 뒤, 주소창에 `cmd`를 입력하고 Enter를 누르면 그 위치에서 명령 프롬프트가 열립니다.)

```
pip install -r requirements.txt
```

웹 화면(Streamlit), API 호출(requests), 설정 파일 읽기(python-dotenv), 사진 줄이기(Pillow)가 설치됩니다. 한 번만 하면 됩니다.

### ③ BAZE API 키 넣기

이 앱은 AI 모델을 **BAZE API 게이트웨이**([안내 문서](https://docs.factchat.kr))로 호출합니다.
(강의에서는 OpenRouter를 썼지만, 같은 방식(OpenAI 호환)의 BAZE로 바꿨습니다.)

1. `Study-04` 폴더에 `.env` 파일이 있는지 봅니다. 없으면 `.env.example`을 복사해서 이름을 `.env`로 바꿉니다.
   - 파일 탐색기에서 `.env`가 안 보이면 [보기] → [파일 확장명]과 [숨긴 항목]을 켜세요.
2. `.env`를 메모장으로 열고, `BAZE_API_KEY=` 바로 뒤에 발급받은 키를 붙여 넣고 저장합니다.

```
BAZE_API_KEY=여기에-발급받은-키를-붙여-넣기
```

- `=` 앞뒤에 띄어쓰기나 따옴표를 넣지 마세요.
- `.env`는 `.gitignore`에 들어 있어서 **GitHub에 올라가지 않습니다.** 키는 다른 사람에게 보여 주거나 채팅에 붙여 넣지 마세요.
- 키는 발급한 BAZE 주소에서만 동작합니다. 다른 주소를 안내받았다면 `BAZE_BASE_URL`도 그 주소로 바꿉니다.

## 2. 실행하기

**방법 A — 더블 클릭 (추천)**: `Study-04` 폴더의 **`run.bat`** 을 더블 클릭합니다.

**방법 B — 명령어**: `Study-04` 폴더에서 아래를 입력합니다.

```
python -m streamlit run app.py
```

잠시 뒤 브라우저에 **http://localhost:8501** 이 열립니다. 자동으로 안 열리면 이 주소를 브라우저 주소창에 직접 입력하세요.

**끄는 방법**: 검은 명령 창을 클릭하고 `Ctrl` + `C`를 누르거나 창을 닫습니다. 브라우저 탭만 닫으면 서버는 계속 켜져 있습니다.

> 이 앱은 내 API 키를 쓰기 때문에 **내 컴퓨터(localhost)에서만** 열리도록 설정되어 있습니다(`.streamlit/config.toml`). 같은 와이파이의 다른 사람은 접속할 수 없습니다.

## 3. 사용 방법

왼쪽 사이드바에서 **재료 인식** / **레시피 추천** 화면을 고를 수 있습니다. 사이드바 아래에는 인식한 재료 수와 추천받은 레시피 수가 보이고,
**연결 설정**을 펼치면 API 키가 설정됐는지와 지금 쓰는 모델을 확인할 수 있습니다.

### 3-1. 재료 인식 (1단계)

1. **냉장고 사진** 칸의 **[Upload]** 를 눌러 사진을 고릅니다. (JPG·PNG·WEBP, 사진을 끌어다 놓아도 됩니다.)
2. 올린 사진이 아래에 미리 보이면 **[재료 인식 시작]** 을 누릅니다.
3. 보통 **10초 안팎**이면 **인식한 재료** 칸에 결과가 나옵니다.
   - 위쪽 초록 태그: 찾은 재료 이름
   - 아래 표: 재료 · 대략적인 양 · 상태(신선함, 손질됨 등)
4. 다른 사진으로 바꾸면 이전 결과는 자동으로 지워집니다.

> 💡 냉장고 안이 밝고, 재료가 가려지지 않게 찍을수록 잘 인식합니다. AI는 비슷하게 생긴 재료(예: 래디시와 적양파)를 헷갈릴 수 있으니, 다음 단계에서 고쳐 주세요.

### 3-2. 레시피 추천으로 넘기기

재료 인식이 끝나면 결과 아래에 **[이 재료로 레시피 추천받기]** 버튼이 나옵니다. 누르면 **레시피 추천 화면으로 넘어가고, 인식한 재료가 그대로 채워집니다.**

사진이 없어도 괜찮습니다. 사이드바에서 **레시피 추천**을 누르고 재료를 직접 입력하면 됩니다.

### 3-3. 재료 고치기

**재료** 칸에 재료가 태그로 들어 있습니다.

- **빼기**: 태그 오른쪽의 **✕** 를 누릅니다.
- **추가하기**: 칸을 클릭하고 재료 이름을 입력한 뒤 **Enter**를 누릅니다.
- **전부 지우기**: 칸 오른쪽의 ⊗ 버튼을 누릅니다.

다른 화면에 갔다 와도 고친 재료는 그대로 남아 있습니다.

### 3-4. 조건 고르기

| 항목 | 고를 수 있는 값 |
| --- | --- |
| 요리 종류 | 상관없음 · 한식 · 양식 · 중식 · 일식 |
| 난이도 | 쉬움 · 보통 · 어려움 |
| 레시피 개수 | 1개 · 2개 · 3개 |
| 인원 | 1명 ~ 4명 (슬라이더) |

### 3-5. 레시피 받기

**[레시피 추천받기]** 를 누르면 몇 초~십몇 초 뒤 레시피 카드가 나옵니다. (재료가 하나도 없으면 버튼이 눌리지 않습니다.)

카드 하나에 이런 내용이 들어 있습니다.

- **요리 이름**과 한 줄 소개
- 파란·보라·회색 태그: **예상 시간 · 난이도 · 인원**
- **가진 재료** (초록): 내 재료 중 이 요리에 쓰는 것
- **추가로 필요** (주황): 사 와야 하는 재료. 소금·식용유 같은 기본 양념도 내 목록에 없으면 여기에 나옵니다.
- **조리 순서**: 번호대로 따라 하면 됩니다.

같은 조건으로 다시 누르면 다른 레시피가 나올 수 있습니다. AI가 만든 레시피이므로 **알레르기 재료와 익힘 정도는 직접 확인**하세요.

## 4. 비용과 속도

AI 요청 1번마다 BAZE 크레딧이 조금씩 쓰입니다(2026-11-17 BAZE 모델 목록 기준).

| 기능 | 모델 | 가격 (100만 토큰당 입력 / 출력) | 실측 |
| --- | --- | --- | --- |
| 재료 인식 | `google/gemma-4-31B-it` | $0.20 / $0.40 | 사진 1장 약 8초, 약 $0.0002 |
| 레시피 추천 | `gpt-6-luna` | $0.10 / $0.50 | 1번에 몇 초~십몇 초 |

- 처음에는 강의와 같은 Gemma 3(`google/gemma-3-27b-it`)를 썼는데, BAZE에서 구버전이라 응답이 19초~60초 이상으로 들쭉날쭉해 후속 모델인 Gemma 4로 바꿨습니다.
- 레시피는 처음에 DeepSeek(`deepseek-v4.1-flash`, $0.30 / $1.20)이었는데, 더 싸고 현행 모델인 GPT `gpt-6-luna`로 바꿨습니다.
- 실패했을 때 저절로 다시 요청하지 않으므로(크레딧 낭비 방지), 필요하면 버튼을 다시 눌러 주세요.

## 5. 문제가 생겼을 때

| 화면에 나온 내용 / 증상 | 원인과 해결 |
| --- | --- |
| "BAZE API 키가 없습니다" 경고, 버튼이 회색 | `.env`에 `BAZE_API_KEY`가 비어 있습니다. 키를 넣고 저장한 뒤 **앱을 껐다 다시 켜세요**(설정은 켤 때 한 번 읽습니다). |
| "API 키가 올바르지 않습니다" (401) | 키를 잘못 붙여 넣었거나 앞뒤에 띄어쓰기가 있습니다. 키를 다시 복사해 넣으세요. |
| "크레딧이 부족합니다" (402) | BAZE 대시보드에서 사용량·한도를 확인하세요. |
| "모델을 찾을 수 없습니다" (404) / "허용되지 않은 모델" (403) | 내 키로 쓸 수 없는 모델입니다. 아래 "모델 바꾸기"를 보세요. |
| "요청이 거부되었습니다" (400) | 그 모델이 사진을 못 읽는 경우입니다. `VISION_MODEL`을 사진을 읽을 수 있는 모델로 바꾸세요. |
| "응답 시간이 초과되었습니다" | 서버가 60초 안에 답하지 않았습니다. 잠시 뒤 다시 누르세요. 자주 그러면 더 빠른 모델로 바꾸세요. |
| "레시피 형식을 이해하지 못했습니다" | AI 답이 정해진 형식이 아니었습니다. 다시 누르면 대부분 해결됩니다. **모델이 보낸 원문 보기**를 펼치면 실제 답을 볼 수 있습니다. |
| "python을 찾을 수 없습니다" | 파이썬을 설치하고 "Add python.exe to PATH"에 체크하세요(1-①). |
| "Streamlit is not installed" | `pip install -r requirements.txt`를 실행하세요(1-②). |
| "Port 8501 is already in use" | 앱이 이미 켜져 있습니다. 브라우저에서 http://localhost:8501 로 들어가거나, 켜져 있는 명령 창을 닫고 다시 실행하세요. |
| 글꼴이 평소와 다름 | 인터넷이 끊기면 Pretendard 글꼴 대신 기본 글꼴로 보입니다. 기능에는 문제없습니다. |

### 모델 바꾸기

코드는 고칠 필요 없이 `.env`의 두 줄만 바꾸고 앱을 다시 켜면 됩니다.

```
VISION_MODEL=google/gemma-4-31B-it
TEXT_MODEL=gpt-6-luna
```

`VISION_MODEL`은 사진에서 재료를 찾는 모델, `TEXT_MODEL`은 레시피를 만드는 모델입니다.
쓸 수 있는 모델 ID는 BAZE 모델 목록(`GET https://api.baze.co/v1/gateway/models/`)에서 확인합니다. 조직·그룹마다 다를 수 있습니다.

## 6. 테스트 (개발자용)

네트워크와 실제 API 키 없이 돌아갑니다(HTTP 호출은 가짜로 바꾸고, 화면은 Streamlit AppTest로 실행).

```
python -m unittest discover -s tests -v
```

- `tests/test_vision.py`: 요청 만들기, 키가 오류 메시지에 안 나오는지, 모델 답 해석(JSON·목록·깨진 답), 상태 코드별 안내
- `tests/test_recipe.py`: 편집한 재료와 조건이 요청에 들어가는지, "계란 2개"처럼 양이 붙어도 가진 재료로 인식하는지, 중복 레시피 제거
- `tests/test_app_flow.py`: 인식한 재료가 레시피 화면으로 넘어가는지, 화면을 왔다 갔다 해도 재료가 남는지, 재료가 없으면 버튼이 꺼지는지
