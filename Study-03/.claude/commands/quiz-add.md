# 새 문제 추가: 과목 **$1**, 난이도 **$2**

## 0. 준비
- 인수 확인: 과목은 키·이름·줄임말·번호(1~5) 중 하나, 난이도는 초급(1)·중급(2)·상급(3). 없거나 틀리면 사용법을 알려 주고 멈춘다.
- `CLAUDE.md`의 **문제 검증 가이드라인 1~7**을 먼저 읽는다.

## 1. 중복 확인
- `node tools/quiz.js list $1` 로 그 과목의 기존 문제를 본다. 같은 개념을 묻는 문제가 있으면 다른 주제를 고른다.
- `node tools/quiz.js next-id $1` 로 새 id를 받는다.

## 2. 문제 작성 (템플릿)
```js
{
  id: "<next-id 결과>", category: "<과목 키>", difficulty: <1|2|3>,
  question: "문제 문장",
  choices: ["보기1", "보기2", "보기3", "보기4"],
  answer: <정답 인덱스 0~3>,
  explanation: "정답인 이유와 핵심 개념. 오답 보기가 왜 틀렸는지도"
}
```
- 정보처리기사 출제기준(Q-net)과 표준 교재로 확인되는 내용만 쓴다. 출처를 사용자에게 함께 알린다.
- 최상급 표현은 기준을 문장에 넣는다. "~이 아닌 것" 문제는 오답 보기 하나하나가 정말 맞는 설명인지 확인한다.
- 코드 출력 문제는 실제로 컴파일·실행해 나온 출력을 정답으로 한다(정의되지 않은 동작 금지). 실행 명령과 출력을 보고에 포함한다.
- 정답 위치(`answer`)는 그 과목에서 가장 적게 쓰인 위치로 정한다(`node tools/quiz.js stats` 참고).

## 3. 추가와 검증
- `js/questions.js`에서 그 과목 문제들 뒤에 넣는다(추가 문제 구역의 같은 과목 묶음 끝).
- `node tests/run.js` 를 실행해 모두 통과해야 한다. 실패하면 고치고 다시 실행한다.
- `node tools/quiz.js dupes` 로 중복이 없는지 한 번 더 확인한다.
