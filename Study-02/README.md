# 개인용 할 일 관리 앱 (My Tasks)

매일 해야 할 일을 적고, 업무·개인·공부 카테고리와 **달력**으로 관리하는 웹 앱입니다.
할 일마다 **메모와 사진**을 붙여 자세한 내용까지 남길 수 있습니다.
프레임워크 없이 **순수 HTML·CSS·자바스크립트**로 만들었고, 설치 없이 브라우저에서 바로 실행됩니다.

> 인공지능활용실습 — 04. 단계별 프롬프트 활용: 개인용 할 일 관리 애플리케이션 제작

## 실행

`index.html`을 **더블 클릭**하면 됩니다. 서버나 설치가 필요 없습니다.

할 일과 메모는 브라우저의 localStorage에, 사진은 IndexedDB에 저장되므로 새로고침하거나 창을 닫아도 남아 있습니다.
다른 컴퓨터로 옮기거나 따로 보관하려면 **내보내기**로 JSON 파일을 받아 두세요(사진도 함께 들어갑니다).

## 강의 예제와 무엇이 다른가

강의 자료의 5단계(기본 기능 → 카테고리 → 대시보드 → 다크 모드·고급 기능 → 최종 완성)에 나온
기능은 모두 넣었습니다. 여기에 더해 아래를 바꾸거나 더했습니다.

| 영역 | 강의 예제 | 이 앱 |
| --- | --- | --- |
| 보기 | 목록만 | **목록 / 달력** 전환. 달력에서는 시작일~마감일이 **선(막대)** 으로 이어짐 |
| 자세한 내용 | 한 줄 제목뿐 | 할 일마다 **메모(여러 줄, 5,000자)** 와 **사진(최대 10장)**. 끌어다 놓기·붙여넣기(Ctrl+V)도 됨 |
| 기간 | — | **시작일·마감일**. `@10/3~10/7`처럼 한 번에 입력 가능 |
| 입력 | 드롭다운으로 카테고리 선택 | 드롭다운도 되고, `자료구조 과제 #과제 @오늘~금`처럼 **한 줄로 빠르게 입력** |
| 삭제 | 확인 창(`confirm`) 후 영구 삭제 | 바로 지우고 **되돌리기** 버튼 / `Ctrl+Z` |
| 완료한 일 | 목록에 섞여 있음 | 아래 **완료됨** 칸으로 따로 모음 (접기 가능) |
| 대시보드 | 전체·카테고리 진행률, 오늘 추가 | 여기에 **오늘 완료, 오늘 마감, 기한 지남, 최근 7일 완료 그래프** |
| 다크 모드 | 토글로만 전환 | 처음엔 **운영체제 설정을 따르고**, 토글로 고를 수 있음. 새로고침 때 깜빡임 없음 |
| 수정 | 더블클릭 → 한 줄 입력창 | 할 일을 누르면(더블클릭도 됨) **상세 창**에서 제목·카테고리·기간·메모·사진을 한 번에 수정 |
| 드래그 정렬 | 마우스 드래그 | 마우스·**터치** 모두 지원, 키보드(`Alt+↑/↓`)로도 이동. 필터 중에 옮겨도 숨은 항목 자리는 그대로 |
| 가져오기 | JSON 덮어쓰기 | **합치기 / 모두 바꾸기**, 가져오기 전 자동 백업, 잘못된 파일은 이유를 알려 줌. **강의 예제 파일도 읽음** |
| 안전성 | — | 입력 내용을 HTML로 해석하지 않음(XSS 방지), 가져온 사진은 이미지 형식만 허용, 저장소를 못 쓰는 환경 안내 |
| 날짜 | — | 한국 시간 오전 0~9시에 날짜가 하루 밀리는 흔한 버그(UTC 변환)를 피함 |
| 다른 탭 | — | 두 탭에 열어도 한쪽 변경이 다른 쪽에 바로 반영 |
| 접근성 | — | 키보드만으로 모든 기능 사용, 화면 낭독기 안내, 동작 줄이기 설정 존중, 색각이상에서도 구분되는 카테고리 색 |
| 검증 | 직접 눌러 보기 | **로직 테스트 32개** + 실제 Chrome으로 클릭하는 화면 테스트 |

## 사용법

### 달력

목록 위의 **[달력]** 을 누르거나 `Alt+C`를 누릅니다.

- 할 일은 **시작일부터 마감일까지 선**으로 이어집니다. 주가 바뀌면 다음 줄로 이어져 그려집니다.
- 시작일을 비우면 **등록한 날부터**, 마감일이 없으면 **그날 하루**(점 표시)로 나옵니다.
- 여러 날에 걸친 일(과제 기간 등)이 먼저 자리를 잡고, 칸이 모자라면 날짜 칸에 `+N`으로 표시됩니다.
- **날짜를 누르면** 아래에 그날 걸친 할 일이 모두 나오고, 여기서 바로 완료 체크할 수 있습니다.
- **선을 누르면** 그 할 일의 상세 창이 열립니다.
- **[이 날 마감으로 추가]** 를 누르면 고른 날짜가 마감일로 채워진 채 입력창으로 갑니다.
- 기한이 지난 일은 빨간색, 완료한 일은 흐리게 표시됩니다. 카테고리 필터와 검색도 그대로 적용됩니다.

### 메모와 사진

할 일을 누르면 상세 창이 열립니다.

- **메모**: 여러 줄로 자세히 적을 수 있습니다(최대 5,000자). 목록에는 첫 줄이 미리 보이고, 검색에도 걸립니다.
- **사진**: [사진 추가]를 누르거나, 창에 파일을 **끌어다 놓거나**, 캡처한 이미지를 **Ctrl+V**로 붙여 넣습니다.
  한 할 일에 10장까지이며, 사진을 누르면 크게 볼 수 있습니다.
  큰 사진은 긴 변 1600px의 JPEG로 줄여서 저장합니다(휴대폰 사진 기준 용량 약 1/10).
- 닫기(X)나 `Esc`는 **저장하고 닫고**, [취소]만 바꾼 내용을 버립니다.

### 빠른 입력

입력창에 아래 표시를 섞어 쓰면 카테고리·마감일·기간이 자동으로 정해집니다.
입력하는 동안 아래에 어떻게 해석됐는지 미리 보여 줍니다.

| 표시 | 뜻 | 예 |
| --- | --- | --- |
| `#업무` `#개인` `#공부` `#과제` | 카테고리 (`#과제`는 공부로) | `#과제` |
| `@오늘` `@내일` `@모레` | 마감일 | `@내일` |
| `@월` ~ `@일`, `@금요일` | 가장 가까운 그 요일 (오늘 포함) | `@금` |
| `@10/5`, `@2026-10-05` | 날짜 (이미 지난 월/일이면 내년) | `@10/5` |
| `@시작~마감` | 기간 | `@10/3~10/7`, `@오늘~금` |

예) `자료구조 과제 #과제 @오늘~10/9` → 공부 카테고리, 오늘부터 10월 9일까지 달력에 선으로 표시

`메일@회사`나 `C#`처럼 단어 중간에 들어간 기호는 그대로 둡니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Alt+N` | 새 할 일 입력창으로 |
| `/` | 검색 (제목·메모) |
| `Alt+1` ~ `Alt+4` | 전체 · 업무 · 개인 · 공부 필터 |
| `Alt+L` / `Alt+C` | 목록 / 달력 보기 |
| `PageUp` / `PageDown` | 달력에서 이전 달 / 다음 달 |
| `Alt+T` | 다크 모드 전환 |
| `Ctrl+Z` | 방금 한 삭제·가져오기 되돌리기 |
| `Enter` / `F2` | 선택한 할 일 상세 창 |
| `Delete` | 선택한 할 일 삭제 |
| `Alt+↑` / `Alt+↓` | 순서 옮기기 (정렬이 "직접 정렬"일 때) |
| `?` | 사용법 창 열기 |

> 강의 예제는 다크 모드에 `Alt+D`를 썼지만, 크롬·엣지에서 `Alt+D`는 주소창으로 가는 단축키와
> 겹치기 때문에 `Alt+T`로 바꿨습니다.

### 정렬 (목록 보기)

직접 정렬(드래그) · 최신순 · 오래된순 · 마감일순 · 카테고리순. 고른 정렬과 보기 방식은 저장됩니다.

## 프로젝트 구조

```
Study-02/
├── index.html          # 화면 구조 (아이콘, 상세 창·사진 보기·가져오기·도움말 대화상자)
├── css/style.css       # 디자인. 색은 모두 변수로 정의하고 다크 모드는 같은 변수에 다른 값
├── js/
│   ├── tasks.js        # 할 일 계산 (빠른 입력, 정렬, 필터, 통계, 달력 배치, 날짜 문구) — DOM 없음
│   ├── storage.js      # 저장·불러오기, 데이터 검증, 가져오기/내보내기 형식 — DOM 없음
│   ├── images.js       # 사진 저장(IndexedDB), 크기 줄이기, 내보내기용 변환
│   └── app.js          # 화면 그리기와 사용자 입력 처리
├── tests/
│   └── logic.test.js   # tasks.js·storage.js 테스트 (Node 내장 테스트 러너)
└── docs/PRD.md         # 기획서 (요구사항)
```

계산(`tasks.js`)과 저장 형식(`storage.js`)을 화면 코드와 분리해서, 브라우저 없이도 Node로 테스트할 수 있게 했습니다.
`index.html`을 더블 클릭해 `file://`로 열어도 동작하도록 ES 모듈 대신 일반 `<script>`로 불러옵니다
(크롬은 `file://`에서 모듈 스크립트를 막습니다).

사진을 localStorage가 아닌 IndexedDB에 두는 이유: localStorage는 브라우저당 약 5MB라 사진 몇 장이면 가득 찹니다.
할 일 데이터에는 사진 id만 적고, 사진 파일(Blob)은 IndexedDB에 따로 보관합니다.
어떤 할 일에도 쓰이지 않게 된 사진은 다음에 앱을 열 때 정리합니다(그 전까지는 되돌리기로 살릴 수 있게 남겨 둠).

## 테스트

```bash
cd Study-02
node --test
```

Node.js 18 이상이면 추가 설치 없이 실행됩니다. 빠른 입력·기간 해석, 정렬, 드래그 순서 계산,
달력 배치(주 넘김, 줄 나누기, `+N`), 메모 정리, 저장 실패·데이터 손상 처리, 사진 형식 검사,
강의 예제 파일 가져오기, 합치기 등 32개 항목을 확인합니다.

화면 동작은 Chrome을 자동으로 조작하는 테스트(playwright)로 따로 확인했습니다. 추가·완료·삭제·되돌리기,
상세 창에서 메모·사진 붙이기와 새로고침 후 유지, 달력 선 표시·날짜 선택·달 이동, 필터·검색·단축키,
드래그, 다크 모드, 사진까지 포함한 내보내기→다른 브라우저로 가져오기, 모바일 화면(375px) 가로 넘침,
입력한 HTML이 실행되지 않는지까지 확인했습니다. 이 테스트 스크립트는 저장소에 넣지 않았습니다.

성능 (할 일 1000개, 데스크톱 Chrome 기준 측정값)

| 동작 | 시간 |
| --- | --- |
| 완료 체크 1번 | 약 6ms |
| 검색어 입력 1글자 (1000개 → 11개로 줄어드는 경우) | 약 40ms |
| 달력으로 전환 (한 달에 1000개) | 약 50ms |

하루 10~20개를 쓰는 기획 기준(100개 이하)에서는 모두 수 ms 수준입니다.

## 데이터 형식

localStorage 키 `personal-todo/data`에 아래 형식으로 저장됩니다. 내보내기 파일은 여기에
`images`(사진 id → data URL)가 더해집니다.

```json
{
  "version": 1,
  "tasks": [
    {
      "id": "…",
      "text": "자료구조 과제",
      "category": "study",
      "start": "2026-10-01",
      "due": "2026-10-09",
      "note": "3장까지 작성\n제출은 LMS",
      "images": ["…사진 id…"],
      "completed": false,
      "createdAt": "2026-10-01T05:26:23.527Z",
      "updatedAt": "2026-10-01T05:26:23.527Z",
      "completedAt": null,
      "order": 0
    }
  ],
  "history": { "2026-10-01": 3 },
  "settings": { "category": "all", "sort": "manual", "theme": "system", "view": "list", "showDone": true, "dashboardOpen": true }
}
```

`history`는 날짜별 완료 개수입니다. 완료한 할 일을 지워도 기록은 남기 때문에 "오늘 완료"와
"최근 7일 완료" 그래프가 줄어들지 않습니다(완료를 취소하면 그날 기록에서 빠집니다). 90일이 지난 기록은 정리합니다.

## 한계

- 데이터는 이 브라우저에만 저장됩니다. 기기 간 이동은 내보내기/가져오기로 합니다.
- 카테고리는 업무·개인·공부 세 가지로 고정입니다(`#과제`는 공부로 들어갑니다).
- 달력에서 선을 끌어 날짜를 바꾸는 기능은 없습니다. 기간은 상세 창에서 고칩니다.
- 되돌리기는 마지막 한 번(삭제·완료 항목 삭제·가져오기)만 됩니다.
- 글꼴(Pretendard)은 인터넷에서 불러오며, 오프라인이면 시스템 글꼴(맑은 고딕 등)로 보입니다.
