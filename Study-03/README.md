# 정보처리기사 퀴즈

정보처리기사 필기 5과목을 4지선다로 풀어 보는 퀴즈 게임입니다.
순수 HTML·CSS·자바스크립트로 만들었고, 설치 없이 브라우저에서 바로 실행됩니다.

> 인공지능활용실습 — 07. 할루시네이션 없는 AI 콘텐츠 만들기

## 실행

`index.html`을 더블 클릭하면 됩니다.

## 게임 방식

- 5과목(소프트웨어 설계 / 소프트웨어 개발 / 데이터베이스 구축 / 프로그래밍 언어 활용 / 정보시스템 구축관리)에서 **과목당 2문제, 총 10문제**를 무작위로 출제합니다. 문제 은행에는 과목당 6문제, 총 30문제가 있습니다.
- 문제를 풀 때마다 **정답 여부와 해설**을 바로 보여 줍니다. 보기 순서는 매번 섞이고, 숫자키 `1`~`4`로도 고를 수 있습니다.
- 끝나면 점수(문제당 10점), 과목별 정답 수, **틀린 문제 복습**을 보여 줍니다.
- **순위표**는 점수가 높은 순, 같으면 시간이 짧은 순으로 상위 10명을 이 브라우저(localStorage)에 저장합니다.

## 할루시네이션 대응 (강의 내용 반영)

강의의 핵심은 "AI가 만든 콘텐츠를 그대로 믿지 말고 검증하라"입니다. 이 프로젝트는 다음과 같이 반영했습니다.

| 강의 내용 | 이 프로젝트 |
| --- | --- |
| 검증 가이드라인을 `CLAUDE.md`에 영구 저장 | [`CLAUDE.md`](CLAUDE.md)에 문제 검증 규칙 7가지를 적어 둠 |
| 논란 있는 정보는 기준을 명시 (예: 가장 긴 강) | 정답이 둘이 될 수 있는 문제는 출제하지 않음. "~이 아닌 것" 문제는 오답 보기까지 검증 |
| 정답과 함께 추가 정보 안내 | 모든 문제에 해설(`explanation`) 포함 |
| 직접 테스트 | `node tests/run.js`로 문제 형식·섞기 후 정답 유지·순위 정렬 검사, 코드 출력 문제는 실제로 컴파일·실행해 확인 |

> **주의**: 문제는 정보처리기사 출제기준과 일반 교재 내용을 바탕으로 작성했으며 기출문제를 그대로 옮긴 것이 아닙니다.
> 시험 대비용으로 쓰기 전에 Q-net(한국산업인력공단)의 출제기준과 교재로 한 번 더 교차 검증하세요.

## 파일 구성

```
Study-03/
├─ index.html          화면
├─ css/style.css       스타일 (다크 모드 자동 대응)
├─ js/questions.js     문제 은행 — 문제를 추가·수정할 때는 여기만 고치면 됩니다
├─ js/quiz-core.js     문제 뽑기·보기 섞기·순위 정렬 로직
├─ js/app.js           화면 처리
├─ tests/run.js        테스트 (node tests/run.js)
└─ CLAUDE.md           프로젝트 설명 + 문제 검증 가이드라인
```

## 문제 추가하기

`js/questions.js`의 `QUESTIONS` 배열에 아래 형식으로 추가하고 `node tests/run.js`를 실행합니다.

```js
{
  id: "d07", category: "design",          // design | develop | database | language | system
  question: "문제 문장",
  choices: ["보기1", "보기2", "보기3", "보기4"],
  answer: 0,                               // 정답 보기의 번호(0부터)
  explanation: "정답인 이유"
}
```

코드 출력 문제는 `code: "소스 코드"` 필드를 추가하면 코드 블록으로 표시됩니다.
