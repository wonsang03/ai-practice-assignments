# PRD 1단계 — 냉장고 사진에서 식재료 인식

> 프로젝트: 냉장고를 부탁해 (Study-04) · 상태: **구현 완료**

## 1. 목표

사용자가 냉장고 내부 사진을 올리면 이미지 인식 AI 모델이 사진 속 식재료를 찾아 목록으로 보여 준다.
이 목록은 2단계(레시피 생성)의 입력이 된다.

## 2. 범위

| 포함 | 제외 (다음 단계 이후) |
| --- | --- |
| 사진 업로드(JPG·PNG·WEBP)와 미리보기 | 재료 직접 수정·추가 (2단계) |
| BAZE 게이트웨이 비전 모델 호출로 재료 인식 | 레시피 생성 (2단계) |
| 재료 이름 + 대략적인 양·상태 표시 | 로그인·저장 (3단계) |
| API 키 누락·호출 실패 시 안내 메시지 | 여러 장 동시 업로드, 카메라 촬영 |

## 3. 기능 요구사항

| ID | 요구사항 |
| --- | --- |
| F1-1 | 사진 1장을 업로드할 수 있다. 허용 형식은 jpg, jpeg, png, webp. |
| F1-2 | 업로드한 사진을 화면에 미리 보여 준다. |
| F1-3 | [재료 인식 시작] 버튼을 누르면 모델을 호출하고, 기다리는 동안 진행 표시(스피너)를 보여 준다. |
| F1-4 | 긴 변이 1568px보다 큰 사진은 비율을 유지한 채 JPEG로 줄여서 보낸다. |
| F1-5 | 결과는 재료 이름 / 양 / 상태 표로 보여 준다. 같은 재료는 한 번만 표시한다(공백·대소문자 무시). |
| F1-6 | 재료를 하나도 찾지 못하면 다른 사진으로 다시 시도하라고 안내한다. |
| F1-7 | 사진을 바꾸면 이전 인식 결과를 지운다. |
| F1-8 | 인식 결과는 세션에 `ingredients`로 보관해 2단계에서 그대로 쓴다. |
| F1-9 | API 키가 없으면 경고를 보여 주고 버튼을 비활성화한다. |

## 5. API 사양

- 엔드포인트: `POST {BAZE_BASE_URL}/chat/completions/` (기본 `https://api.baze.co/v1/gateway`, OpenAI 호환)
- 인증: `Authorization: Bearer <BAZE_API_KEY>` — 키는 `.env`에서만 읽는다.
- 모델: `.env`의 `VISION_MODEL` (기본 `google/gemma-4-31B-it`. 강의의 Gemma 3 27B는 BAZE에서 구버전이라 느리고 들쭉날쭉해(실측 19초~60초 초과) 후속 모델로 바꿈. 같은 사진 8초)
- 요청 본문:

```json
{
  "model": "google/gemma-4-31B-it",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "…JSON으로만 답하라는 지시…"},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,…"}}
    ]
  }],
  "temperature": 0.2
}
```

- 기대 응답(모델 답 본문): `{"ingredients": [{"name": "계란", "quantity": "약 6개", "state": "신선"}]}`
- 해석 순서: ```` ```json ```` 코드 블록 안 JSON → 본문 속 JSON → `- 계란` / `1. 우유` / `계란, 우유` 같은 목록. 문자열 배열도 받는다.

## 6. 오류 처리

| 상황 | 안내 |
| --- | --- |
| 키 없음 | `.env`에 `BAZE_API_KEY`를 넣으라는 경고, 요청 안 보냄 |
| 401 | API 키가 올바르지 않음 |
| 400 | 모델이 이미지 입력을 지원하지 않거나 파일 문제 — 비전 모델로 바꾸라고 안내 |
| 402 | BAZE 크레딧(사용 한도) 부족 |
| 403 | API로 쓸 수 없거나 이 키에 허용되지 않은 모델 — `VISION_MODEL` 변경 |
| 404 | 모델 없음 — BAZE 모델 목록(`/models/`)에서 ID 확인 |
| 429 | 요청 한도 초과 — 잠시 후 재시도 |
| 5xx | BAZE 서버 문제 |
| 시간 초과(60초)·연결 실패 | 각각 안내 |
| 200 응답 안의 `error` | 위 코드표와 같은 안내 |
| 이미지가 아님 | 사진 파일을 확인하라는 안내 |

오류 메시지와 로그에는 API 키를 절대 넣지 않는다.
