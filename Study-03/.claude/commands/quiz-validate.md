# 최상급 표현 검증

검증 대상 과목: **$ARGUMENTS** (비어 있으면 전체 문제)

CLAUDE.md 문제 검증 가이드라인 2번("정답은 하나로 명확해야 한다")을 점검한다.
최상급 표현은 측정 기준이 없으면 정답 논란이 생긴다(예: '가장 긴 강' — 길이 측정 기준에 따라 답이 다름).

## 순서

1. `node tools/quiz.js superlatives $ARGUMENTS` 를 실행해 후보 문제를 가져온다. 직접 세거나 기억으로 찾지 않는다.
2. 후보마다 판단한다.
   - **기준 명확**: 표준 교재에 순서·기준이 정해져 있다(예: 응집도·결합도 강도 순서). 해설에 그 순서가 적혀 있는지도 확인한다.
   - **모호**: 기준이 문제에 없거나 교재마다 다르다 → 기준을 문제 문장에 넣는 수정안을 만든다.
   - 단어가 들어 있지만 최상급 판단이 아닌 경우(해설 속 설명 등)는 "해당 없음"으로 둔다.
3. 표로 보고한다: `id | 찾은 단어 | 판단 | 이유 | 수정안`.
4. **모호** 판정이 있으면 수정안을 보여 준 뒤 `js/questions.js`를 고친다. 정답이나 보기를 바꾸면 가이드라인 1~5를 다시 지킨다(출처 확인, 오답 보기 검증, 해설 보완).
5. 수정했다면 `node tests/run.js` 를 실행해 모두 통과하는지 확인하고 결과를 보고한다.

확신이 없는 판단은 "확인 필요"로 표시하고 사용자에게 묻는다(가이드라인 6).
